# Курс «JavaScript: за 10 уроков» / "JavaScript: in 10 lessons"

> Курс состоит из **10 тем** и посвящён языку программирования JavaScript — от первой программы в консоли браузера до разработки полноценного интерактивного веб-проекта. По завершении обучения студент владеет синтаксисом, типами данных, массивами, объектами, условиями, циклами, функциями, работой с датами, DOM и событиями, а также умеет создавать приложения с сохранением данных в браузере.
>
> The course consists of **10 lessons** dedicated to the JavaScript programming language — from your first program in the browser console to building a full interactive web project. Upon completion, students master syntax, data types, arrays, objects, conditionals, loops, functions, dates, DOM and events, and can build browser applications with persistent data storage.

## Предварительные требования / Prerequisites

Для прохождения этого курса необходимы базовые знания HTML (структура документа, семантические теги) и CSS (селекторы, стилизация). DOM-часть курса (урок 9) напрямую опирается на разметку HTML. Рекомендуется пройти курсы [«HTML: за 10 уроков»](https://github.com/JLearn-space/HTML) и [«CSS: за 10 уроков»](https://github.com/JLearn-space/CSS) перед началом обучения.

To take this course, basic knowledge of HTML (document structure, semantic tags) and CSS (selectors, styling) is required. The DOM part of the course (lesson 9) directly relies on HTML markup. It is recommended to complete the ["HTML: in 10 lessons"](https://github.com/JLearn-space/HTML) and ["CSS: in 10 lessons"](https://github.com/JLearn-space/CSS) courses before starting.
