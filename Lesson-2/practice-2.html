Урок 2: Переменные и типы данных

1. Создание переменных

let — изменяемая переменная, const — константа, var — устаревший способ.

2. Примитивные типы данных

Строки, числа, логический тип, null, undefined — и для каждого можно узнать тип через оператор typeof.

3. Шаблонные строки

Обратные кавычки позволяют встраивать выражения через ${}.

4. Преобразование типов

Явное (String(), Number()) и неявное ('5' + 3) преобразование.
